# 🌸 Chibi Kawaii Planner (v2.2.4)

A soft, playful, single-file HTML5 weekly planner web application with dedicated daily pages, chibi mascots, mood trackers, habit pips, water intake, local storage persistence, and JSON/CSV export options.

## ✨ Features
- 📅 **Multi-Week Document Support**: Manage multiple named weekly planners seamlessly.
- 💾 **Auto-Save**: Background auto-save every 800ms directly to local storage.
- 🏷️ **Version Control & Migration**: Built-in schema migration and versioning (`v2.2.4`).
- 🖨️ **Print Ready**: Optimized `@media print` layout (1 page per day, 8 pages total for a full week).
- 📱 **Fully Responsive**: Mobile, tablet, and desktop friendly layout.
- ⬇️ **Export & Import**: Export data to JSON backups or CSV format, and import JSON backups anytime.
- ✦ **Add Art / Custom Deco**: Floating sakura, sparkles, paws, soft clouds, and floating hearts decorations.

## 🚀 Usage
Simply open `chibi.html` in any modern web browser! No build tools or backend server required.
